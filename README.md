# TES Arena 向けの非公式MOD

「日本語化」0.40 は、Steam 版の The Elder Scrolls: Arena を日本語で遊べるようにする、非公式のファン翻訳・改造です。日本語化に加え、地図や買い物の操作改善、戦闘の調整、依頼や自宅の追加などを含みます。

最後まで通しでクリアできることは確認しています。問題があれば [Issues](https://github.com/miyaya55/tes_arena_mods/issues) に書いていただければ、時々見て対処するかもしれません。

GitHub に画像を載せる手順が面倒だったので、主な機能の追加・変更は note に書いています。

[Claude CodeでTES ArenaのModを作成した（note）](https://note.com/mimimi241/n/nb568b916d2d2)

## 地図・探索・依頼

- 自動地図に、メインクエストの品・救出する人・鍵の印を表示します。町の地図では、扉を建物の種類で色分けし、聞き込みで聞いた場所を枠で囲みます。地図の右には色の説明を表示します。
- メインクエストの区切り（リアの夢、町の噂、頼みの承諾・辞退、依頼の品、迷宮の場所、杖の欠片）で、次にすることを語りの窓で知らせます。また、メインクエストの道を尋ねるものも、関連する話題が出た時は窓で通知するようにしました。
- 元のゲームでは出なかった依頼を作り直しました。「宮殿の守り」では宮殿で襲撃者と戦い、「店の見張り」では夜まで店の前で休み、現れたならず者を倒します。
- 8つ目の欠片を手に入れたあとに休むと、元のゲームでは出なかった（らしい）リアの最後の夢が見られます。
- 石の砦では、羊皮紙を取るまで、ゴブリンの首領で死霊術師のゴルソグが待ち構えます。島の周囲のグールをすべて倒すと、グールの死体が消えてゴルソグが現れます。オリジナル版では名前があるのに出なかったので追加しました。容姿はゴブリン風にしてます。
- 迷宮の謎かけで答えを入力するとき、F1 を押すとリアが答えを教えてくれます。答えの表示は英語です。
- 敵が持ち歩いている鍵は、死体を1回クリックするとすべて受け取れます。水晶の塔の飼育係のトロールなどが対象で、鍵を見つけたことを文章でも知らせます。
- 「帰還の巻物」を、魔術師ギルドと迷宮の魔法屋の水薬の一覧で金貨1000枚から買えます。迷宮内で「使う」から読むと、扉から出たときと同じ扱いで入口の外へ出ます。近くに敵がいても使えます。

## 迷宮の宿・店と町の会話

- メインクエストの16の迷宮の入口近くに、宿屋・武器屋・魔法屋の NPC がいる部屋を追加します。敵は部屋に入ってきません。店の人はそれぞれの言葉で話し、交渉・修理・鑑定に応じます。迷宮の魔法屋で呪文を買うときも、それぞれの言葉で交渉します。
- 迷宮の宿では、町の酒場と同じく、酒・部屋を借りる・部屋に忍び込む・噂・手当てを選べます。宿の主人の部屋には、町の宿と同じ形のベッドがあります。部屋を借りるとその場で朝まで休み、朝になっても治っていなければ治るまで眠り続けます。夜の娼婦のところに泊まる場合や、部屋に忍び込む場合も同じです。
- 迷宮の店で盗みに失敗したり、店の人を殴ったりすると反撃してきます。迷宮を出ると元に戻ります。
- 武器・防具屋と迷宮の酒場のメニューを、縦に長くならない2列表示にします。
- 町の夜の娼婦に「買う」を選ぶと朝まで泊まり、次に迷宮に入って出るまで、すべての能力が5上がります。

## 買い物・修理・鑑定

- 武器・防具屋の「買う」「売る」では、品の行を1回クリックするたびに印（■）を付け外しできます。【一括購入】【一括売却】で、印を付けた品をまとめて取引できます。価格交渉は合計額について1回行います。購入時に持ち物の空き・重さ・お金が足りなければ、印を減らすよう知らせます。装備中の品は一括売却できません。一覧の先頭2行は、ほかの一覧と同じく2回のクリックで決定します。
- 売却の一覧を購入と同じ横長の表示にし、品名の右に交渉前の売値を表示します。クエストの品・壊れた品は「売れない」、装備中の品は「装備中」と表示します。購入・売却の見出しも日本語になります（品名・使う手・部位・重さ・値段・売値）。
- 売却の一覧の【並び：種類順】を押すと【並び：手に入れた順】に切り替わり、最後に入手した品が一番上になります。もう一度押すと種類順に戻ります。装備中の品はどちらでも一番下です。
- 修理は全店合わせて10品まで預けられ、どの店でも受け取れます。預かり一覧には「（あと3日）」などの残り時間か「（完了）」を表示します。修理済みの品が2品以上あれば、先頭の行からまとめて受け取れます。
- 武器・防具屋の「強化」では、お金を払って素材を1段階上げられます（鉄→鋼鉄→銀→…→黒檀）。
- 鑑定の一覧には、鑑定が必要な品だけを表示します。魔術師ギルドと迷宮の魔法屋では、品名の右に鑑定料を表示し、その日の料金が0なら「無料」と表示します。対象が2品以上なら【すべて鑑定】でまとめて鑑定できます。お金が足りない場合は、一覧の上から順に払える品だけを鑑定するか確認します。
- 店や魔術師ギルドで「盗む」を選ぶと、実行前に確認します。

## 画面表示・キャラクター操作

- 日本語版で作ったセーブは、保存・読み込みの一覧で名前が黄色になります。最も新しいセーブには「最新」、メインクエストを最後まで終えたセーブには「クリア」の印が付きます。マウスを載せた枠の保存日時を一覧の下に表示します。
- ステータス画面とボーナス点の画面では、項目名を右クリックすると説明が出ます。キャラクター作成の職業一覧でも、職業名の右クリックで紹介と能力・装備・特技の説明を読めます。マニュアルと実際のゲームで異なる部分は、ゲームの内容に合わせています。
- ステータス画面の能力・装備の頁で未装備状態の体を左クリックすると、普段着を着脱できます。脱がせると、元のゲームの絵の体（裸）がそのまま表示されます。性的な描写はありません。
- 右の欄の「使う」では、同じ薬を1行にまとめて「×3」のように本数を表示します。使用回数のある魔法の品には「5回」のように残り回数を表示します。魔法力を戻す水薬の名前は「魔法力回復の薬」です。
- 画面下のボタンから開く状態の窓に、呪文の盾の残り点数と、時間で切れる効果の残り時間を表示します。表示例は「（盾の残り50点）」「（あと12分）」です。透明・浮遊・抵抗・毒・能力の強化などが対象です。
- 呪文名を日本語にします。
- 素手で戦うときの拳を、種族の肌の色に合わせます。レッドガードは褐色、ダークエルフとアルゴニアンは青灰、ハイエルフは金茶です。ブレトン・ノルド・ウッドエルフ・カジートは元のままです。

## 戦闘・成長

- 敵の呪文の強さ、レベルアップ時の体力、意志力による呪文ダメージの軽減を調整し、受けた・与えたダメージを数字で表示します。
- レベルの上がり方は序盤をゆるやかにし、一定のレベルが上がるごとに攻撃と防御を少し底上げします。
- 呪文で敵に与えたダメージを、炎・冷気・毒・電撃の効き具合で色分けします。効果が増えたときは黄、減ったときは水色、効かないときは灰色の「0」、敵が回復したときは緑の「+n」です。受けたダメージは赤で表示します。
- 生き物に殴られたときの麻痺を、呪文への抵抗が効いている間も防ぎます。呪文の盾など、状態の窓で「呪文に強い」と表示される効果が対象です。元のゲームでは、毒への抵抗が効いている間と、ハイエルフ・騎士だけが防げました。

## 自分の家

- 石の砦の羊皮紙をリハドの女王に届けると、3階建ての屋敷を金貨5000枚で勧められます。購入後は大陸の地図の左下に家の印と「家へ」が現れ、どこからでも帰宅できます。外を歩けない迷宮を出るときの地図からも使えます。家を出るときは屋内で地図を開いて旅をし、来る前の町・迷宮にも戻れます。家で休むと宿の最上の部屋と同じだけ回復し、現在地は「自分の家」と表示されます。
- メイドのソレイユは、丁寧な毒舌で話します。二段のメニューから「あなたは？」「話す」「物置」を選べます。「話す」では世間話、メインクエストと依頼の進み具合、増築や家の出方を聞けます。購入後・増築後の帰宅時にはひとこと出迎えます。殴るとはたきで反撃し、負けると眠らされてベッドの横で目覚めます。
- ソレイユの休日には、おどおどした見習いメイドのリネットが代わりに来ます。休日はゲーム内でおよそ20日に1日です。帰宅後に初めて話しかけると、不在の理由を説明します。できることはソレイユと同じですが、殴るとほうきで反撃します。家を買った最初の日は必ずソレイユがいます。
- ソレイユか1階の物置の箱から、持ち物を100品まで預けられます。印を付けて、まとめて預けたり引き出したりできます。
- 3階の主寝室の姿見には、妖精のステラとルナが住んでいます。話しかけるとかけあいで話し、「着替える」を選ぶと装備の頁を開きます。元々は外見変更に使おうとしましたが、面倒だったため着替えるにとどめてます。
- 購入後にリハドの女王へ話しかけると、金貨3000・5000・8000枚の3段階で、閉じた部屋を開けてもらえます。1段階目で1階の彫像の間に鍛冶屋、2段階目で2階の温室に魔術師ギルド、3段階目で3階の書斎に神殿の司祭が入ります。町の店と同じメニューを使え、自動地図には町の扉と同じ色の印が付きます。盗みに失敗したり殴ったりすると襲ってきますが、負けてもベッドの横で目覚めます。

## 不具合の修正・メモリー使用の改善

- 台から降りたときに縁に挟まる元のゲームの不具合を修正します。どの向きにも進めないときだけ、隣の通れるマスの中央へ押し出します。
- 泳いでいるとき、水面の敵に進路をふさがれる元のゲームの不具合を修正します。泳いでいる間は敵の下を通れますが、岸に上がる場所に敵がいる場合は上がれません。
- 店やギルドで盗んだあと、品ぞろえが壊れたり画面が固まったりする不具合を修正します。
- 町の人の返事に武器屋の名前が入る台詞で、ゲームが固まる・落ちる不具合を修正します。
- 呪文を唱える敵が多いとき、呪文の弾が上限を超えて別のデータを書き換える不具合を修正します。
- 呪文で画面の色が変わったあと、読み込みのたびにメモリーが減り、読み込みを繰り返すとゲームが固まる・落ちる不具合を修正します。
- 死亡後の New Start で、冒頭の語りの音声が終了後に別のメモリーへ書き込み、「Insufficient Base Memory!」「Memory list blown!」で止まる不具合を修正します。
- 日本語化によるメモリー使用の増加を抑え、「Insufficient Base Memory!」による停止を防ぐための対策を行います。
- 呪文書で説明を見てから EXIT で戻ると、画面が崩れる不具合を修正します。
- 取った鍵が、階段で別の階へ行って戻ると台の上に再出現する不具合を修正します。
